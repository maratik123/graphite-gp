**Badge** — a small mono status pill. Use for track validity, race state, or short counts.

```jsx
<Badge tone="ok">VALID</Badge>
<Badge tone="warn">RUN-OUT</Badge>
<Badge tone="danger" solid>CRASH</Badge>
<Badge tone="accent">Vmax 7</Badge>
```

Tones: `neutral | accent | ok | warn | danger`. `solid` fills the tone color.
