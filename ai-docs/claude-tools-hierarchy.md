## Hooks (`.claude/settings.json`)
| Event | Purpose |
|-------|---------|
| SessionStart | `ast-index` update/rebuild; read-rules reminder |
| PreToolUse (Bash `git commit`) | **branch-guard** — block commits on `main` (`exit 2` + recovery recipe); refresh `ast-index` |
| PreToolUse (Bash, `curl`/`wget` + `crates.io/api`) | **crates-io-ua** — block a crates.io API fetch carrying no User-Agent (`exit 2`). crates.io rejects UA-less requests with a JSON *error body*, so `jq -r '.crate.max_stable_version'` prints a literal `null` and **exits 0** — the AGENTS.md § *Dependency Versions* AXIOM reports success while the fact was never obtained. Fires when the command text contains `crates.io/api` **and** a `curl`/`wget` token at a word boundary **and** no User-Agent. UA is detected by *text*, not flag spacing: a literal `User-Agent:` / `user-agent=` anywhere (covering `-H`, `-H"…"`, `-sSH "…"`, `--header`), or `--user-agent <v>`, or an `-A`-style flag (`-A "v"`, `-A'v'`, `-sSA "v"`). **Known limitation — it matches command TEXT, not shell semantics:** it cannot distinguish a real fetch from a heredoc or `sed` that merely *quotes* one, so those fail closed; the block message says so and names the workaround. It is a backstop for the common shape, not a proof. Escalated 2026-07-16 from `ai-docs/learnings.md`; the rule existed and was escalated, but the *recipe it prescribed* was the failure, and the failure is silent. |
| PreToolUse (Bash, `git push` / `gh pr …`) | **code-writer-push-guard** — when the calling subagent is `code-writer` (input `agent_type == "code-writer"`), block `git push` and `gh pr create/edit/merge/ready/comment/close` (`exit 2`). Enforces the code-writer Invariant that the orchestrator owns push + Step-12 PR ops (`.claude/agents/code-writer.md`). Main-thread and other-subagent calls carry no / a different `agent_type` and pass through; `git commit`/`git add` are untouched (Mode A commits legitimately). Escalated 2026-07-21 from `ai-docs/learnings.md` (4× recurrence #44/#47/#52/#56) after charter wording alone failed. |
| PreToolUse (Agent\|Task) | **code-writer-spawn-guard** — when `agent_type == "code-writer"`, block any subagent spawn whose `subagent_type != "image-check"` (`exit 2`). Enforces "you ARE the implementor" — the only permitted spawn is `image-check` at a golden mint. Main-thread / `context-reset` spawns of `code-writer` pass through (they carry no `agent_type` "code-writer"). Same 2026-07-21 escalation. |
| PostToolUse (Write\|Edit) | `cargo fmt` on `.rs`; **panic-gate** — flag `.unwrap()/.expect(/panic!` outside `#[cfg(test)]` |
| PostToolUse (Bash `git push`) | **pr-sync** — remind to re-read/sync the open PR body |
